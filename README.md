# DAY-1-PUBG_MUHAMMAD_RAFIE_TAYMORIAN_MARWAN

1. Deskripsi mengenai repository :
   
 Repository adalah tempat penyimpanan proyek atau kumpulan file yang dikelola menggunakan Git. Repository berfungsi untuk menyimpan seluruh file proyek serta mencatat setiap perubahan yang dilakukan sehingga riwayat pengerjaan dapat dilihat kembali.

2. tujuan dan kegunaannya :
   
- Menyimpan proyek: Menjadi tempat untuk menyimpan file dan kode program.
- Mencatat perubahan: Menyimpan riwayat perubahan pada proyek.
- Mengelola versi: Memudahkan pengguna melihat atau kembali ke versi sebelumnya.
- Memudahkan kolaborasi: Memungkinkan beberapa orang bekerja bersama dalam satu proyek.
- Menjaga proyek tetap terorganisir: Membantu mengatur file dan perkembangan proyek agar lebih mudah dikelola.
  
3.Rangkuman Materi Woekshop :

Materi yang disampaikan yaitu penggunaan Artificial Intelligence (AI) untuk membantu proses pembuatan aplikasi serta pengenalan Git dan GitHub. Materi pertama membahas Prompt Engineering, yaitu cara memberikan perintah yang jelas dan spesifik kepada AI agar menghasilkan jawaban sesuai kebutuhan.
Kami juga diperkenalkan dengan beberapa platform AI seperti Claude, Antigravity, dan ChatGPT. Selanjutnya, kami mempelajari Git sebagai alat untuk mencatat perubahan pada proyek dan GitHub sebagai tempat menyimpan repository secara online.
Selain itu, kami belajar alur kerja Git, mulai dari membuat repository, menyimpan perubahan, hingga mengunggah proyek ke GitHub menggunakan beberapa perintah dasar seperti git init, git add, git commit, dan git push.

4. Poin Poin penting atau pengetahuan baru :
   
- Prompt Engineering: Cara membuat perintah yang jelas dan spesifik agar AI dapat memberikan hasil yang sesuai.
- Penggunaan AI: AI dapat membantu proses pembuatan aplikasi dan website.
- Git: Digunakan untuk mencatat dan mengelola perubahan pada file proyek.
- GitHub: Digunakan untuk menyimpan proyek secara online dan memudahkan kerja sama.
- Repository: Tempat untuk menyimpan file proyek beserta riwayat perubahannya.
- Perintah Git: Mengenal beberapa perintah seperti git init, git add, git commit, dan git push.
